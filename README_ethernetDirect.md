# LAN File Transfer — LAN / Wi-Fi / Ethernet Direct

ブラウザーから受信側PCへファイルを転送する Flask アプリケーションです。通常のLAN/Wi-Fi接続と、PC同士をEthernetケーブルで直結する接続の両方に対応します。チャンク分割、再試行、一時停止、キャンセル、フォルダー階層の保持を備えています。

## 起動方法

Python 3.10 以降を使用します。プロジェクトフォルダーで次を実行してください。

```powershell
python -m pip install -r requirements.txt
python LAN_file_transfer.py
```

受信側（ファイルを保存する側）のPCで起動します。初回起動時に `file_transfar_config.yaml` を生成し、`ACCESS_TOKEN` に認証用トークンを設定します。トークンは受信側PCのコンソールに表示されるため、送信側ブラウザーの「転送認証トークン」欄に入力してください。

受信ファイルは既定で `uploads` フォルダーに保存されます。接続先や保存先、チャンクサイズなどは `file_transfar_config.yaml` で変更できます。既存インストールとの互換性のため、設定ファイル名の綴り `file_transfar_config.yaml` は維持しています。

## 保持される情報

- ファイル内容はバイト列を変換せずに転送します。画像・音声・文書などのファイル内部に埋め込まれたメタデータは、ファイル内容の一部として保持されます。
- ブラウザーが公開する `File.lastModified` を受信ファイルの最終更新日時に反映します。
- フォルダー選択時はブラウザーが提供する相対パスを使い、サブフォルダー階層を再作成します。
- ブラウザーの標準ファイル選択からは、作成日時、アクセス日時、所有者、ACL、代替データストリームなどを通常取得できません。そのため、これらのOSレベルの属性は保持対象外です。

## PCをEthernetで直結する

1. 2台のPCのEthernetポートをLANケーブルで接続します。
2. 受信側PCのEthernet IPv4を `192.168.50.1`、サブネットマスクを `255.255.255.0` に設定します。デフォルトゲートウェイとDNSは空欄で構いません。
3. 送信側PCのEthernet IPv4を `192.168.50.2`、サブネットマスクを `255.255.255.0` に設定します。IPアドレスは2台で重複させないでください。
4. 受信側PCでアプリを起動し、送信側PCのブラウザーで `http://192.168.50.1:5000` を開きます。
5. 認証トークンを入力し、ファイルまたはフォルダーを選択してアップロードします。

画面上部の「接続方法」で直結モードを選ぶと、設定手順、推奨URL、およびこのPCで検出したIPv4アドレスが表示されます。アプリはOSのIP設定を自動変更しません。

## セキュリティ上の注意

- 転送認証トークンが必要です。設定ファイルを第三者に渡さないでください。
- 通信はHTTPで暗号化されません。信頼できるプライベートLANまたは直結ネットワーク内でのみ使用してください。
- ルーターのポート転送やインターネットへの直接公開は行わないでください。Windowsファイアウォールで受信通信を許可する場合も、信頼できるプライベートネットワークに限定してください。
- 保存先相対パス、アップロードID、チャンク番号、チャンクサイズを検証し、保存先外へのパストラバーサルを防ぎます。
- 起動時には未完了転送の一時ファイルをクリアします。一時フォルダーを保存先と同じ場所やその配下に設定しないでください。

## 設定例

```yaml
RETRY_LIM: 3
CHUNK_SIZE: 5242880
UPLOAD_FOLDER: uploads
TEMP_FOLDER: temp_uploads
HOST: "0.0.0.0"
PORT: 5000
DIRECT_ETHERNET_IP: "192.168.50.1"
DIRECT_ETHERNET_SUBNET_MASK: "255.255.255.0"
ACCESS_TOKEN: "" # 空欄の場合は起動時に生成して保存
```

`192.168.50.0/24` が既存ネットワークと重複する場合は、設定ファイルの `DIRECT_ETHERNET_IP` と `DIRECT_ETHERNET_SUBNET_MASK` を、重複しないアドレスに合わせて変更してください。送信側PCのIP設定も同じサブネットに合わせる必要があります。
