# LAN File Transfer — イーサネット直結

既存のブラウザー経由のファイル転送に、**PC同士をLANケーブルで直接接続するための案内モード**を追加しています。転送処理自体はこれまでどおり、チャンク分割・再試行・一時停止・キャンセルに対応したHTTPアップロードです。

## 起動方法

Python で Flask と PyYAML が利用できる環境で、プロジェクトフォルダーから実行します。

```bash
python -m pip install flask pyyaml
python LAN_file_transfer.py
```

受信側（ファイルの保存先にするPC）で起動してください。受信ファイルは `uploads` フォルダーに保存されます。

## PCをイーサネット直結して転送する

1. 2台のPCの Ethernet ポートをLANケーブルで接続します。通常はストレートケーブルで構いません。リンクランプが点灯しない場合は、ケーブルやアダプターの対応状況を確認してください。
2. **受信側PC**の Ethernet アダプターの IPv4 を `192.168.50.1`、サブネットマスクを `255.255.255.0` に設定します。デフォルトゲートウェイとDNSは空欄で構いません。
3. **送信側PC**の Ethernet アダプターの IPv4 を `192.168.50.2`、サブネットマスクを `255.255.255.0` に設定します。2台で同じIPアドレスを設定しないでください。
4. 受信側PCでアプリを起動し、送信側PCのブラウザーで `http://192.168.50.1:5000` を開きます。
5. 送信側PCでファイルやフォルダーを選択してアップロードします。受信ファイルは受信側PCの `uploads` に保存されます。

画面上部の「接続方法」で「PC同士をイーサネット直結」を選ぶと、設定手順、推奨URL、およびこのPCで検出したIPv4アドレスが表示されます。

### Windowsの設定場所

「設定」→「ネットワークとインターネット」→「イーサネット」→「IP 割り当て」の「編集」から「手動」→「IPv4」を有効にし、IPアドレスとサブネットマスクを入力します。Windowsのバージョンによって項目名は多少異なります。

### 注意事項

- この機能はWindowsなどのOSのIP設定を自動変更しません。ネットワーク設定は各PCで行ってください。
- ファイアウォールで通信が遮断される場合は、信頼できるプライベートネットワークでのみ、受信側のTCPポート `5000` への受信通信を許可してください。公衆ネットワークで広く公開しないでください。
- `192.168.50.0/24` が既存ネットワークと重複する場合は、設定ファイル `file_transfar_config.yaml` の `DIRECT_ETHERNET_IP` と `DIRECT_ETHERNET_SUBNET_MASK`、およびこのREADME内の両PCのIP設定を、重複しないアドレスに合わせて変更してください。
- アプリは既定で `0.0.0.0:5000` で待ち受けるため、直結のほか、従来どおり同じLAN/Wi-Fi上のPCからもアクセスできます。
