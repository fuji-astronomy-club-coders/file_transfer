# LAN File Transfer (v2) 仕様書および取扱説明書

## 概要

本システムは、ローカルエリアネットワーク（LAN）内において、Webブラウザを介して大容量ファイルおよびフォルダの安全かつ効率的な送受信を実現するPython (Flask) ベースのファイル転送サーバーアプリケーションです。

バージョン2への更新に伴い、チャンク分割送信、レジューム（中断・再開）処理、複数ファイルの一括キュー管理、詳細なアクセスログ出力機能が実装・強化されています。

---

## 主な機能仕様

* **複数ファイルおよびフォルダの一括送信**
* 複数ファイルの同時選択、ならびに `webkitdirectory` 属性を利用したフォルダ構造単位での選択に対応しています。

* **アップロードキュー管理**
* 選択されたファイルをキューとして管理し、送信待機中ファイルの削除や進捗状況の個別に管理が可能です。

* **チャンク分割アップロード**
* 大容量ファイルを指定したサイズに分割して送信することにより、ネットワークの負荷軽減およびタイムアウトの防止を図っています。

* **一時停止・再開およびキャンセル機能**
* 送信処理の一時停止および再開が可能です。また、キャンセル時にはサーバー側に生成された一時ファイルを自動的に消去します。

* **重複ファイル確認**
* 同名のファイルが既にサーバー上に存在する場合、上書き実行またはスキップの選択ダイアログを表示します。

* **YAML設定ファイルによるパラメータ管理**
* ホストアドレス、ポート番号、チャンクサイズ、リトライ上限回数などのパラメータを外部設定ファイル（`file_transfar_config.yaml`）から制御可能です。ファイルが存在しない場合は初回起動時に自動生成されます。

* **詳細なロギング**
* 稼働ログは標準出力への表示に加え、`logs/` ディレクトリ配下に日時が付与されたファイルとして保存されます。

## 動作環境

* **Python**: 3.x 以降
* **依存ライブラリ**:
* Flask
* PyYAML
* Werkzeug

### ライブラリのインストール

```bash
pip install Flask PyYAML Werkzeug

```

## 設定パラメータ (`file_transfar_config.yaml`)

本アプリケーションは、同一ディレクトリ内の `file_transfar_config.yaml` から設定を読み込みます。

```yaml
RETRY_LIM: 3           # 通信エラー発生時の最大リトライ回数
CHUNK_SIZE: 5242880    # 分割送信時の1チャンクあたりのサイズ（バイト単位、デフォルト: 5MB）
UPLOAD_FOLDER: uploads # アップロード完了ファイルの保存先ディレクトリ
TEMP_FOLDER: temp_uploads # 転送一時ファイルの保存先ディレクトリ
HOST: "0.0.0.0"        # サーバーのバインドIPアドレス
PORT: 5000             # 使用ポート番号

```

## 使用方法

### 1. サーバーの起動

コマンドラインから以下のコマンドを実行してサーバーを起動します。

```bash
python LAN_file_transfer.py

```

起動時、ターミナルにアクセス可能なローカルIPアドレスおよびポート番号が表示されます（例: `[http://192.168.](http://192.168.)X.X:5000`）。

### 2. クライアントからの接続

同一LANに接続されているクライアント端末のWebブラウザを起動し、表示されたURLへアクセスします。

### 3. ファイル送信手順

1. **ファイル選択** または **フォルダ選択** から送信対象のデータを選択します。
2. **「アップロード開始」** ボタンを選択し、転送を開始します。
3. 画面上に表示される進捗バー、転送速度、および予測完了時間を確認します。

* **一時停止 / 再開**: 通信を一時的に停止し、必要に応じて再開可能です。
* **キャンセル**: 処理を中止し、サーバー上の一時データを削除します。

1. 正常に完了したファイルは、サーバー上の `uploads/` ディレクトリへ保存されます。

## ディレクトリ構成

本システムの実行に伴い、以下のディレクトリ構造が自動的に生成・管理されます。

* `uploads/`: 転送が完了したファイルの保存先ディレクトリ
* `temp_uploads/`: 転送中および分割データの保持用一時ディレクトリ（起動時およびキャンセル時に自動清掃）
* `logs/`: サーバーの実行ログファイル保存先ディレクトリ
